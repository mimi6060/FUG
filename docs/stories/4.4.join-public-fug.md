# Story 4.4: Join Public FUG Event

## Status
Draft

## Story
**As a** registered user,
**I want** to join a public FUG event,
**so that** I can participate and meet other users

## Acceptance Criteria
1. "Join" button visible on public event details
2. Clicking Join adds user to event participants
3. Participant count updates in real-time
4. User sees event in "My Events" list
5. Event creator is notified of new participant
6. User cannot join if event is full (max participants)
7. User cannot join past events

### EventRepository.joinEvent Implementation
```dart
Future<void> joinEvent(String eventId) async {
  final userId = await getCurrentUserId();

  // Check if already participant
  final existing = await databases.listDocuments(
    databaseId: databaseId,
    collectionId: 'event_participants',
    queries: [
      Query.equal('eventId', eventId),
      Query.equal('userId', userId),
    ],
  );
  if (existing.documents.isNotEmpty) {
    throw AlreadyJoinedException();
  }

  // Create participant document
  await databases.createDocument(
    databaseId: databaseId,
    collectionId: 'event_participants',
    documentId: ID.unique(),
    data: {
      'eventId': eventId,
      'userId': userId,
      'status': 'joined',
      'joinedAt': DateTime.now().toIso8601String(),
    },
  );

  // Update participant count (via Appwrite Function or direct update)
  // Send notification to creator
}
```
