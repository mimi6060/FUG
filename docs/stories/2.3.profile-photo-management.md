### Key Implementation
```dart
Future<String> uploadAvatar({
  required String userId,
  required File imageFile,
}) async {
  // Delete old avatar if exists
  final user = await getUserProfile(userId);
  if (user?.avatar != null) {
    await storage.deleteFile(bucketId: 'avatars', fileId: user!.avatar!);
  }

  // Upload new avatar
  final file = await storage.createFile(
    bucketId: 'avatars',
    fileId: ID.unique(),
    file: InputFile.fromPath(path: imageFile.path),
  );

  // Update user profile with new avatar ID
  await databases.updateDocument(
    databaseId: databaseId,
    collectionId: 'users',
    documentId: userId,
    data: {'avatar': file.$id},
  );

  return file.$id;
}
```

### Storage Bucket
- Bucket ID: `avatars`
- Max file size: 5MB
- Allowed types: jpg, png, webp
