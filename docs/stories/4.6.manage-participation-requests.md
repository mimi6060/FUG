# Story 4.6: Manage Participation Requests

## Status
Draft

## Story
**As an** event creator,
**I want** to approve or decline participation requests,
**so that** I can control who joins my private FUG

## Acceptance Criteria
1. Creator sees pending requests in event management
2. Each request shows requester name, avatar, and profile link
3. Creator can approve a request (user becomes participant)
4. Creator can decline a request (user is notified)
5. Approved user receives notification and event appears in their list
6. Declined user receives notification with reason (optional)

Future<void> approveParticipation(String participantId, String eventId) async {
  // Update status
  await databases.updateDocument(
    databaseId: databaseId,
    collectionId: 'event_participants',
    documentId: participantId,
    data: {
      'status': 'joined',
      'approvedAt': DateTime.now().toIso8601String(),
    },
  );

  // Increment participant count
  final event = await databases.getDocument(databaseId, 'events', eventId);
  await databases.updateDocument(
    databaseId: databaseId,
    collectionId: 'events',
    documentId: eventId,
    data: {'participantCount': event.data['participantCount'] + 1},
  );

  // Notify user
  await notificationService.send(

}
