# Story 6.1: Badge System (Gamification)

## Status
Draft

## Story
**As a** registered user,
**I want** to earn badges for my activities,
**so that** I feel rewarded and motivated to participate

## Acceptance Criteria
1. User can view their earned badges in profile
2. Badges are awarded automatically based on triggers
3. User receives notification when earning a badge
4. Badge details show name, description, and earn date
5. Badges display on public profile
6. System supports multiple badge categories

### Appwrite Function: award-badge
```javascript
module.exports = async function(context) {
  const { userId, badgeId } = JSON.parse(context.req.body);

  // Check if already earned
  const existing = await databases.listDocuments(
    databaseId, 'user_achievements',
    [Query.equal('userId', userId), Query.equal('achievementId', badgeId)]
  );
  if (existing.total > 0) return { awarded: false, reason: 'already_earned' };

  // Get badge info
  const badge = BADGES[badgeId];
  if (!badge) return { awarded: false, reason: 'badge_not_found' };

  // Award badge
  await databases.createDocument(
    databaseId, 'user_achievements', ID.unique(),
    { userId, achievementId: badgeId, unlockedAt: new Date().toISOString() }
  );

  // Add points to user
  const user = await databases.getDocument(databaseId, 'users', oderId);
  await databases.updateDocument(
    databaseId, 'users', userId,
    { points: user.points + badge.points }
  );

  // Send notification
  await sendPushNotification(userId, 'Badge Earned!', badge.name);

  return { awarded: true, badge };
};
```

### Collections Required
- `achievements`: Badge definitions (name, description, icon, points)
- `user_achievements`: User earned badges (userId, achievementId, unlockedAt)
