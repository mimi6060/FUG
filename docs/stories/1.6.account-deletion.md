# Story 1.6: Account Deletion (GDPR Compliance)

## Status
Draft

## Story
**As a** registered user,
**I want** to delete my account and all associated data,
**so that** I can exercise my GDPR right to be forgotten

## Acceptance Criteria
1. User can access "Delete Account" option in profile settings
2. Confirmation dialog warns about irreversible data loss
3. User must re-enter password to confirm deletion
4. All user data is deleted from Appwrite collections
5. User session is terminated and redirected to login
6. Deletion is logged for audit purposes

### AuthRepository.deleteAccount Implementation
```dart
Future<void> deleteAccount(String password) async {
  // 1. Re-authenticate to verify password
  final user = await account.get();
  await account.createEmailPasswordSession(
    email: user.email,
    password: password,
  );

  // 2. Delete user data from all collections
  await databases.deleteDocument(databaseId, 'users', user.$id);
  // ... delete from other collections

  // 3. Delete avatar from storage
  if (user.prefs['avatarFileId'] != null) {
    await storage.deleteFile('avatars', user.prefs['avatarFileId']);
  }

  // 4. Delete Appwrite account
  await account.updateStatus(); // Mark inactive
  // Note: Full deletion requires server-side function

  // 5. Sign out
  await signOut();
}
```
