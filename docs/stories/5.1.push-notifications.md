# Story 5.1: Push Notifications (FCM/APNs)

## Status
Draft

## Story
**As a** registered user,
**I want** to receive push notifications on my device,
**so that** I stay informed about FUG events and social activity

## Acceptance Criteria
1. User is prompted for notification permission on first launch
2. FCM token is stored in user profile
3. User receives push notification when:
   - Someone follows them
   - They're invited to an event
   - Event they joined is starting soon
   - Event they created has new participant
4. Tapping notification opens relevant screen
5. Notifications work on both iOS and Android

### NotificationService Implementation
```dart
class NotificationService {
  final FirebaseMessaging _fcm = FirebaseMessaging.instance;

  Future<void> initialize() async {
    // Request permission
    final settings = await _fcm.requestPermission(
      alert: true,
      badge: true,
      sound: true,
    );

    if (settings.authorizationStatus == AuthorizationStatus.authorized) {
      // Get token
      final token = await _fcm.getToken();
      await _saveToken(token);

      // Listen for token refresh
      _fcm.onTokenRefresh.listen(_saveToken);

      // Handle messages
      FirebaseMessaging.onMessage.listen(_handleForegroundMessage);
      FirebaseMessaging.onMessageOpenedApp.listen(_handleNotificationTap);
    }
  }

  Future<void> _saveToken(String? token) async {
    if (token != null) {
      await profileRepository.updateFcmToken(token);
    }
  }

  void _handleNotificationTap(RemoteMessage message) {
    final data = message.data;
    switch (data['type']) {
      case 'new_follower':
        router.go('/profile/${data['userId']}');
        break;
      case 'event_invite':
        router.go('/event/${data['eventId']}');
        break;
      // ... other types
    }
  }
}
```

```javascript
  const fcmToken = user.fcmToken;

  if (!fcmToken) return context.res.json({ sent: false });

  // Send via FCM
  await admin.messaging().send({
    token: fcmToken,
    notification: { title, body },
    data,
  });

  return context.res.json({ sent: true });
};
```
