# Story 4.5: Request to Join Private FUG

## Status
Draft

## Story
**As a** registered user,
**I want** to request to join a private FUG event,
**so that** the creator can approve my participation

## Acceptance Criteria
1. "Request to Join" button visible on private event details
2. Clicking sends a participation request to the creator
3. Request status shows "Pending" for the user
4. Creator receives notification about the request
5. User cannot request twice for the same event
6. User is notified when request is approved/declined

## Dev Notes

### EventRepository.requestToJoin
```dart
Future<void> requestToJoin(String eventId) async {
  final userId = await getCurrentUserId();

  // Check if already requested
  final existing = await databases.listDocuments(
    databaseId: databaseId,
    collectionId: 'event_participants',
    queries: [
      Query.equal('eventId', eventId),
      Query.equal('userId', userId),
    ],
  );
  if (existing.documents.isNotEmpty) {
    throw AlreadyRequestedException();
  }

  // Create pending participation
  await databases.createDocument(
    databaseId: databaseId,
    collectionId: 'event_participants',
    documentId: ID.unique(),
    data: {
      'eventId': eventId,
      'userId': userId,
      'status': 'pending',
      'requestedAt': DateTime.now().toIso8601String(),
    },
  );

  // Notify creator (via function or direct)
}
```
