### Key Implementation
Profile screen handles both own and other user views:
```dart
class ProfileScreen extends ConsumerWidget {
  final String? userId; // null = current user

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final isOwnProfile = userId == null;
    final profileId = userId ?? ref.watch(currentUserProvider)?.id;

    // Different UI for own vs other profile
    return isOwnProfile
      ? _buildOwnProfile(context, ref)
      : _buildPublicProfile(context, ref, profileId);
  }
}
```
