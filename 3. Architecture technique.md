### 1.2 Avantages de l'architecture Appwrite

Cette architecture basee sur **Appwrite** offre de nombreux avantages:

| Avantage | Description |
|----------|-------------|
| **Backend-as-a-Service** | Infrastructure complete geree, pas de serveur a maintenir |
| **SDK Flutter natif** | Integration fluide avec le SDK Appwrite pour Dart/Flutter |
| **Realtime integre** | WebSocket natif pour les mises a jour en temps reel |
| **Auth complete** | OAuth2 avec Google, Facebook, Apple, email/password |
| **Geospatial natif** | Support des colonnes SPATIAL dans la base de donnees |
| **Functions serverless** | Logique metier custom en Dart ou Node.js |
| **Push notifications** | Messaging integre pour APNs et FCM |
| **Cout reduit** | Plan gratuit genereux, scaling progressif |

## 2. Stack technique Appwrite

### 2.1 Backend - Appwrite

| Composant | Service Appwrite | Description |
|-----------|------------------|-------------|
| **Plateforme** | Appwrite Cloud ou Self-hosted | BaaS complet avec console d'administration |
| **Base de donnees** | Appwrite Database | MariaDB avec support Spatial Columns |
| **Authentification** | Appwrite Auth | OAuth2 (Google, Facebook, Apple), Email/Password, Magic URL |
| **Temps reel** | Appwrite Realtime | WebSocket pour subscriptions aux documents et collections |
| **Notifications push** | Appwrite Messaging | Support APNs (iOS) et FCM (Android) |
| **Stockage fichiers** | Appwrite Storage | Buckets pour avatars, images evenements |
| **Functions serverless** | Appwrite Functions | Dart, Node.js, Python, PHP, Ruby, .NET |

**Justification du choix Appwrite:**
- SDK Flutter mature et bien documente
- Console d'administration intuitive
- Open-source avec option self-hosted
- Support natif des requetes geospatiales
- Realtime integre sans configuration supplementaire
- Communaute active et mises a jour frequentes

### 2.2 Application mobile - Flutter

| Composant | Technologie | Justification |
|-----------|-------------|---------------|
| **Framework** | Flutter 3.x (Dart) | Application unique pour Android, iOS et Web |
| **SDK Backend** | appwrite: ^12.0.0 | SDK officiel Appwrite pour Dart |
| **State Management** | Riverpod 2.x | Gestion d'etat moderne et testable |
| **Navigation** | GoRouter | Navigation declarative |
| **Maps** | google_maps_flutter | Affichage de la carte et des evenements |
| **Localisation** | geolocator | Position GPS de l'utilisateur |
| **Stockage local** | Hive ou Isar | Cache hors-ligne |
| **DI** | get_it + injectable | Injection de dependances |

**Architecture mobile recommandee:**

### 4.2 Function: follow-user

**Description:** Gere le systeme de follow/unfollow entre utilisateurs.

**Trigger:** HTTP POST
**Runtime:** Dart

```dart
import 'dart:convert';
import 'package:dart_appwrite/dart_appwrite.dart';

Future<dynamic> main(final context) async {
  final client = Client()
    .setEndpoint(Platform.environment['APPWRITE_ENDPOINT']!)
    .setProject(Platform.environment['APPWRITE_PROJECT_ID']!)
    .setKey(Platform.environment['APPWRITE_API_KEY']!);

  final databases = Databases(client);
  final users = Users(client);

  // Recuperer les donnees de la requete
  final data = jsonDecode(context.req.body);
  final followerId = context.req.headers['x-appwrite-user-id'];
  final followeeId = data['followee_id'];
  final action = data['action']; // 'follow' ou 'unfollow'

  if (followerId == followeeId) {
    return context.res.json({
      'success': false,
      'message': 'Impossible de se suivre soi-meme'
    }, 400);
  }

  try {
    if (action == 'follow') {
      // Verifier si deja suivi
      final existing = await databases.listDocuments(
        databaseId: 'fug_database',
        collectionId: 'followers',
        queries: [
          Query.equal('follower_id', followerId),
          Query.equal('followee_id', followeeId),
        ],
      );

      if (existing.documents.isNotEmpty) {
        return context.res.json({
          'success': false,
          'message': 'Deja suivi'
        }, 400);
      }

      // Creer le follow
      await databases.createDocument(
        databaseId: 'fug_database',
        collectionId: 'followers',
        documentId: ID.unique(),
        data: {
          'follower_id': followerId,
          'followee_id': followeeId,
        },
      );

      // Creer notification pour le followee
      await databases.createDocument(
        databaseId: 'fug_database',
        collectionId: 'notifications',
        documentId: ID.unique(),
        data: {
          'user_id': followeeId,
          'type': 'new_follower',
          'title': 'Nouveau follower',
          'body': 'Quelqu\'un a commence a vous suivre',
          'data': jsonEncode({'follower_id': followerId}),
          'is_read': false,
          'is_pushed': false,
        },
      );

      return context.res.json({
        'success': true,
        'message': 'Follow cree'
      });

    } else if (action == 'unfollow') {
      // Trouver et supprimer le follow
      final existing = await databases.listDocuments(
        databaseId: 'fug_database',
        collectionId: 'followers',
        queries: [
          Query.equal('follower_id', followerId),
          Query.equal('followee_id', followeeId),
        ],
      );

      if (existing.documents.isEmpty) {
        return context.res.json({
          'success': false,
          'message': 'Follow non trouve'
        }, 404);
      }

      await databases.deleteDocument(
        databaseId: 'fug_database',
        collectionId: 'followers',
        documentId: existing.documents.first.$id,
      );

      return context.res.json({
        'success': true,
        'message': 'Unfollow effectue'
      });
    }

    return context.res.json({
      'success': false,
      'message': 'Action invalide'
    }, 400);

  } catch (e) {
    return context.res.json({
      'success': false,
      'message': 'Erreur: ${e.toString()}'
    }, 500);
  }
}
```

### 4.3 Function: join-event

**Description:** Gere l'inscription et la desinscription aux evenements.

**Trigger:** HTTP POST
**Runtime:** Dart

```dart
import 'dart:convert';
import 'package:dart_appwrite/dart_appwrite.dart';

Future<dynamic> main(final context) async {
  final client = Client()
    .setEndpoint(Platform.environment['APPWRITE_ENDPOINT']!)
    .setProject(Platform.environment['APPWRITE_PROJECT_ID']!)
    .setKey(Platform.environment['APPWRITE_API_KEY']!);

  final databases = Databases(client);

  final data = jsonDecode(context.req.body);
  final userId = context.req.headers['x-appwrite-user-id'];
  final eventId = data['event_id'];
  final action = data['action']; // 'join' ou 'leave'

  try {
    // Recuperer l'evenement
    final event = await databases.getDocument(
      databaseId: 'fug_database',
      collectionId: 'events',
      documentId: eventId,
    );

    if (action == 'join') {
      // Verifier si l'evenement est complet
      final maxParticipants = event.data['max_participants'];
      final currentParticipants = event.data['current_participants'];

      if (maxParticipants != null && currentParticipants >= maxParticipants) {
        return context.res.json({
          'success': false,
          'message': 'Evenement complet'
        }, 400);
      }

      // Verifier si deja inscrit
      final existing = await databases.listDocuments(
        databaseId: 'fug_database',
        collectionId: 'event_participants',
        queries: [
          Query.equal('event_id', eventId),
          Query.equal('user_id', userId),
          Query.notEqual('status', 'left'),
        ],
      );

      if (existing.documents.isNotEmpty) {
        return context.res.json({
          'success': false,
          'message': 'Deja inscrit'
        }, 400);
      }

      // Creer la participation
      final participant = await databases.createDocument(
        databaseId: 'fug_database',
        collectionId: 'event_participants',
        documentId: ID.unique(),
        data: {
          'event_id': eventId,
          'user_id': userId,
          'status': 'confirmed',
          'role': 'participant',
          'joined_at': DateTime.now().toIso8601String(),
        },
      );

      // Incrementer le compteur
      await databases.updateDocument(
        databaseId: 'fug_database',
        collectionId: 'events',
        documentId: eventId,
        data: {
          'current_participants': currentParticipants + 1,
        },
      );

      // Mettre a jour les stats utilisateur
      final user = await databases.getDocument(
        databaseId: 'fug_database',
        collectionId: 'users',
        documentId: userId,
      );

      await databases.updateDocument(
        databaseId: 'fug_database',
        collectionId: 'users',
        documentId: userId,
        data: {
          'total_events_joined': user.data['total_events_joined'] + 1,
        },
      );

      return context.res.json({
        'success': true,
        'message': 'Inscription reussie',
        'participant': participant.data,
      });

    } else if (action == 'leave') {
      // Trouver la participation
      final existing = await databases.listDocuments(
        databaseId: 'fug_database',
        collectionId: 'event_participants',
        queries: [
          Query.equal('event_id', eventId),
          Query.equal('user_id', userId),
          Query.equal('status', 'confirmed'),
        ],
      );

      if (existing.documents.isEmpty) {
        return context.res.json({
          'success': false,
          'message': 'Participation non trouvee'
        }, 404);
      }

      // Mettre a jour le statut
      await databases.updateDocument(
        databaseId: 'fug_database',
        collectionId: 'event_participants',
        documentId: existing.documents.first.$id,
        data: {
          'status': 'left',
          'left_at': DateTime.now().toIso8601String(),
        },
      );

      // Decrementer le compteur
      final currentParticipants = event.data['current_participants'];
      await databases.updateDocument(
        databaseId: 'fug_database',
        collectionId: 'events',
        documentId: eventId,
        data: {
          'current_participants': currentParticipants - 1,
        },
      );

      return context.res.json({
        'success': true,
        'message': 'Desinscription reussie'
      });
    }

    return context.res.json({
      'success': false,
      'message': 'Action invalide'
    }, 400);

  } catch (e) {
    return context.res.json({
      'success': false,
      'message': 'Erreur: ${e.toString()}'
    }, 500);
  }
```

### 4.4 Function: nearby-events

**Description:** Recherche les evenements a proximite d'une position donnee en utilisant les requetes geospatiales.

**Trigger:** HTTP GET
**Runtime:** Dart

```dart
import 'dart:convert';
import 'dart:math';
import 'package:dart_appwrite/dart_appwrite.dart';

Future<dynamic> main(final context) async {
  final client = Client()
    .setEndpoint(Platform.environment['APPWRITE_ENDPOINT']!)
    .setProject(Platform.environment['APPWRITE_PROJECT_ID']!)
    .setKey(Platform.environment['APPWRITE_API_KEY']!);

  final databases = Databases(client);

  // Parametres de la requete
  final latitude = double.parse(context.req.query['latitude'] ?? '0');
  final longitude = double.parse(context.req.query['longitude'] ?? '0');
  final radiusKm = double.parse(context.req.query['radius'] ?? '10');
  final limit = int.parse(context.req.query['limit'] ?? '20');
  final offset = int.parse(context.req.query['offset'] ?? '0');

  try {
    // Requete geospatiale avec Query.distanceLessThan()
    final events = await databases.listDocuments(
      databaseId: 'fug_database',
      collectionId: 'events',
      queries: [
        // Filtre geospatial - rayon en metres
        Query.distanceLessThan(
          'location',
          longitude,  // Attention: longitude en premier
          latitude,
          radiusKm * 1000, // Conversion km -> metres
        ),
        // Filtrer par statut actif
        Query.equal('status', 'active'),
        // Evenements futurs uniquement
        Query.greaterThan('starts_at', DateTime.now().toIso8601String()),
        // Trier par date
        Query.orderAsc('starts_at'),
        // Pagination
        Query.limit(limit),
        Query.offset(offset),
      ],
    );

    // Enrichir avec la distance calculee
    final enrichedEvents = events.documents.map((doc) {
      final eventLat = doc.data['location']['coordinates'][1];
      final eventLng = doc.data['location']['coordinates'][0];
      final distance = _calculateDistance(
        latitude, longitude,
        eventLat, eventLng,
      );

      return {
        ...doc.data,
        '\$id': doc.$id,
        'distance_km': distance,
        'distance_formatted': _formatDistance(distance),
      };
    }).toList();

    // Trier par distance
    enrichedEvents.sort((a, b) =>
      (a['distance_km'] as double).compareTo(b['distance_km'] as double)
    );

    return context.res.json({
      'success': true,
      'total': events.total,
      'events': enrichedEvents,
    });

  } catch (e) {
    return context.res.json({
      'success': false,
      'message': 'Erreur: ${e.toString()}'
    }, 500);
  }
}

// Formule de Haversine pour calculer la distance
double _calculateDistance(
  double lat1, double lon1,
  double lat2, double lon2,
) {
  const R = 6371.0; // Rayon de la Terre en km
  final dLat = _toRadians(lat2 - lat1);
  final dLon = _toRadians(lon2 - lon1);

  final a = sin(dLat / 2) * sin(dLat / 2) +
      cos(_toRadians(lat1)) * cos(_toRadians(lat2)) *
      sin(dLon / 2) * sin(dLon / 2);

  final c = 2 * atan2(sqrt(a), sqrt(1 - a));
  return R * c;
}

double _toRadians(double degree) => degree * pi / 180;

String _formatDistance(double km) {
  if (km < 1) {
    return '${(km * 1000).round()} m';
  }
  return '${km.toStringAsFixed(1)} km';
}
```

### 4.5 Function: gamification

**Description:** Gere le systeme de gamification (points, niveaux, achievements).

**Trigger:** Event (databases.*.collections.*.documents.*)

```dart
import 'dart:convert';
import 'package:dart_appwrite/dart_appwrite.dart';

Future<dynamic> main(final context) async {
  final client = Client()
    .setEndpoint(Platform.environment['APPWRITE_ENDPOINT']!)
    .setProject(Platform.environment['APPWRITE_PROJECT_ID']!)
    .setKey(Platform.environment['APPWRITE_API_KEY']!);

  final databases = Databases(client);

  // Recuperer l'evenement declencheur
  final event = context.req.headers['x-appwrite-event'];
  final payload = jsonDecode(context.req.body);

  try {
    String? userId;
    int pointsToAdd = 0;
    String? achievementToCheck;

    // Determiner l'action et les points
    if (event.contains('events') && event.contains('create')) {
      // Nouvel evenement cree
      userId = payload['creator_id'];
      pointsToAdd = 10;
      achievementToCheck = 'events_created';

    } else if (event.contains('event_participants') && event.contains('create')) {
      // Nouvelle participation
      userId = payload['user_id'];
      pointsToAdd = 5;
      achievementToCheck = 'events_joined';

    } else if (event.contains('followers') && event.contains('create')) {
      // Nouveau follower
      userId = payload['followee_id'];
      pointsToAdd = 2;
      achievementToCheck = 'followers_count';
    }

    if (userId == null) {
      return context.res.json({'success': true, 'message': 'Pas d\'action'});
    }

    // Recuperer l'utilisateur
    final user = await databases.getDocument(
      databaseId: 'fug_database',
      collectionId: 'users',
      documentId: userId,
    );

    // Calculer le nouveau score et niveau
    final newScore = user.data['murgilarity_score'] + pointsToAdd;
    final newLevel = _calculateLevel(newScore);

    // Mettre a jour l'utilisateur
    await databases.updateDocument(
      databaseId: 'fug_database',
      collectionId: 'users',
      documentId: userId,
      data: {
        'murgilarity_score': newScore,
        'level': newLevel,
      },
    );

    // Verifier les achievements
    if (achievementToCheck != null) {
      await _checkAchievements(
        databases,
        userId,
        achievementToCheck,
        user.data,
      );
    }

    return context.res.json({
      'success': true,
      'points_added': pointsToAdd,
      'new_score': newScore,
      'new_level': newLevel,
    });

  } catch (e) {
    return context.res.json({
      'success': false,
      'message': 'Erreur: ${e.toString()}'
    }, 500);
  }
}

int _calculateLevel(int score) {
  // Formule de niveau: sqrt(score / 10)
  return (sqrt(score / 10)).floor() + 1;
}

Future<void> _checkAchievements(
  Databases databases,
  String userId,
  String criteriaType,
  Map<String, dynamic> userData,
) async {
  // Recuperer tous les achievements actifs
  final achievements = await databases.listDocuments(
    databaseId: 'fug_database',
    collectionId: 'achievements',
    queries: [Query.equal('is_active', true)],
  );

  for (final achievement in achievements.documents) {
    final criteria = jsonDecode(achievement.data['criteria']);

    if (criteria['type'] != criteriaType) continue;

    // Verifier si deja debloque
    final existing = await databases.listDocuments(
      databaseId: 'fug_database',
      collectionId: 'user_achievements',
      queries: [
        Query.equal('user_id', userId),
        Query.equal('achievement_id', achievement.$id),
      ],
    );

    if (existing.documents.isNotEmpty) continue;

    // Verifier le seuil
    int currentValue = 0;
    switch (criteriaType) {
      case 'events_created':
        currentValue = userData['total_events_created'];
        break;
      case 'events_joined':
        currentValue = userData['total_events_joined'];
        break;
      case 'followers_count':
        final followers = await databases.listDocuments(
          databaseId: 'fug_database',
          collectionId: 'followers',
          queries: [Query.equal('followee_id', userId)],
        );
        currentValue = followers.total;
        break;
      case 'murgilarity_score':
        currentValue = userData['murgilarity_score'];
        break;
    }

    if (currentValue >= criteria['threshold']) {
      // Debloquer l'achievement
      await databases.createDocument(
        databaseId: 'fug_database',
        collectionId: 'user_achievements',
        documentId: ID.unique(),
        data: {
          'user_id': userId,
          'achievement_id': achievement.$id,
          'unlocked_at': DateTime.now().toIso8601String(),
          'progress': currentValue,
        },
      );

      // Creer notification
      await databases.createDocument(
        databaseId: 'fug_database',
        collectionId: 'notifications',
        documentId: ID.unique(),
        data: {
          'user_id': userId,
          'type': 'achievement_unlocked',
          'title': 'Badge debloque !',
          'body': 'Vous avez obtenu le badge "${achievement.data['name']}"',
          'data': jsonEncode({
            'achievement_id': achievement.$id,
            'achievement_code': achievement.data['code'],
          }),
          'is_read': false,
          'is_pushed': false,
        },
      );
    }
  }
}
```

### 4.7 Function: cleanup-events (Scheduled)

```dart
    .setProject(Platform.environment['APPWRITE_PROJECT_ID']!)
    .setKey(Platform.environment['APPWRITE_API_KEY']!);

  try {
    // 1. Marquer les evenements en cours comme "ongoing"

      databaseId: 'fug_database',
      collectionId: 'events',
      queries: [
        Query.equal('status', 'active'),
        Query.lessThanEqual('starts_at', now.toIso8601String()),

      await databases.updateDocument(
        databaseId: 'fug_database',
        collectionId: 'events',
        documentId: event.$id,
        data: {'status': 'ongoing'},
      );
    }

    // 2. Marquer les evenements termines comme "completed"
    final endedEvents = await databases.listDocuments(
      databaseId: 'fug_database',
      collectionId: 'events',
      queries: [
        Query.equal('status', 'ongoing'),
        Query.isNotNull('ends_at'),
        Query.lessThan('ends_at', now.toIso8601String()),
      ],
    );

    for (final event in endedEvents.documents) {
      await databases.updateDocument(
        databaseId: 'fug_database',
        collectionId: 'events',
        documentId: event.$id,
        data: {'status': 'completed'},
      );
    }

    // 3. Auto-completer les evenements "ongoing" depuis plus de 6h
    final sixHoursAgo = now.subtract(Duration(hours: 6));
    final staleEvents = await databases.listDocuments(
      databaseId: 'fug_database',
      collectionId: 'events',
      queries: [
        Query.equal('status', 'ongoing'),
        Query.isNull('ends_at'),
        Query.lessThan('starts_at', sixHoursAgo.toIso8601String()),
      ],
    );

    for (final event in staleEvents.documents) {
      await databases.updateDocument(
        databaseId: 'fug_database',
        collectionId: 'events',
        documentId: event.$id,
        data: {'status': 'completed'},
      );
    }

    return context.res.json({
      'success': true,
      'started': startedEvents.documents.length,
      'ended': endedEvents.documents.length,
      'stale_completed': staleEvents.documents.length,
    });

  } catch (e) {
    return context.res.json({
      'success': false,
      'message': 'Erreur: ${e.toString()}'
    }, 500);
```

```dart
class RealtimeService {
  final Realtime _realtime;

  // S'abonner aux nouveaux evenements a proximite
  RealtimeSubscription subscribeToNearbyEvents({
    required Function(RealtimeMessage) onEvent,
  }) {
    return _realtime.subscribe([
      'databases.fug_database.collections.events.documents',
    ]).stream.listen((event) {
      if (event.events.contains('databases.*.collections.*.documents.*.create')) {
        onEvent(event);
      }
    });
  }

  // S'abonner aux notifications de l'utilisateur
  RealtimeSubscription subscribeToNotifications({
    required String userId,
    required Function(RealtimeMessage) onNotification,
  }) {
    return _realtime.subscribe([
      'databases.fug_database.collections.notifications.documents',
    ]).stream.listen((event) {
      final payload = event.payload;
      if (payload['user_id'] == userId) {
        onNotification(event);
      }
    });
  }

  // S'abonner aux mises a jour d'un evenement
  RealtimeSubscription subscribeToEvent({
    required String eventId,
    required Function(RealtimeMessage) onUpdate,
  }) {
    return _realtime.subscribe([
      'databases.fug_database.collections.events.documents.$eventId',
      'databases.fug_database.collections.event_participants.documents',
    ]).stream.listen((event) {
      onUpdate(event);
    });
  }
}
```

#### Strategie de cache avec Hive

```dart
// Cache local avec Hive
@HiveType(typeId: 0)
class CachedEvent extends HiveObject {
  @HiveField(0)
  final String id;

  @HiveField(1)
  final String title;

  @HiveField(2)
  final double latitude;

  @HiveField(3)
  final double longitude;

  @HiveField(4)
  final DateTime startsAt;

  @HiveField(5)
  final DateTime cachedAt;

  CachedEvent({
    required this.id,
    required this.title,
    required this.latitude,
    required this.longitude,
    required this.startsAt,
    required this.cachedAt,
  });
}

class OfflineEventRepository {
  final Box<CachedEvent> _eventsBox;

  Future<void> cacheEvents(List<Event> events) async {
    final cachedEvents = events.map((e) => CachedEvent(
      id: e.id,
      title: e.title,
      latitude: e.latitude,
      longitude: e.longitude,
      startsAt: e.startsAt,
      cachedAt: DateTime.now(),
    )).toList();

    await _eventsBox.clear();
    await _eventsBox.addAll(cachedEvents);
  }

  List<CachedEvent> getCachedEvents() {
    return _eventsBox.values
        .where((e) => e.startsAt.isAfter(DateTime.now()))
        .toList();
  }

  bool isCacheValid() {
    if (_eventsBox.isEmpty) return false;
    final lastCached = _eventsBox.values.first.cachedAt;
    return DateTime.now().difference(lastCached).inMinutes < 30;
  }
}
```

#### File d'attente pour actions hors-ligne

```dart
@HiveType(typeId: 1)
class PendingAction extends HiveObject {
  @HiveField(0)
  final String id;

  @HiveField(1)
  final String type; // 'join_event', 'leave_event', 'create_event'

  @HiveField(2)
  final String payload; // JSON

  @HiveField(3)
  final DateTime createdAt;

  @HiveField(4)
  int retryCount;

  PendingAction({
    required this.id,
    required this.type,
    required this.payload,
    required this.createdAt,
    this.retryCount = 0,
  });
}

class OfflineSyncService {
  final Box<PendingAction> _pendingActionsBox;
  final EventService _eventService;
  final ConnectivityService _connectivityService;

  Future<void> queueAction(String type, Map<String, dynamic> payload) async {
    final action = PendingAction(
      id: const Uuid().v4(),
      type: type,
      payload: jsonEncode(payload),
      createdAt: DateTime.now(),
    );
    await _pendingActionsBox.add(action);
  }

  Future<void> syncPendingActions() async {
    if (!await _connectivityService.isConnected()) return;

    final pendingActions = _pendingActionsBox.values.toList();

    for (final action in pendingActions) {
      try {
        await _executeAction(action);
        await action.delete();
      } catch (e) {
        action.retryCount++;
        if (action.retryCount >= 3) {
          await action.delete();
          // Notifier l'utilisateur de l'echec
        } else {
          await action.save();
        }
      }
    }
  }

  Future<void> _executeAction(PendingAction action) async {
    final payload = jsonDecode(action.payload);

    switch (action.type) {
      case 'join_event':
        await _eventService.joinEvent(payload['event_id']);
        break;
      case 'leave_event':
        await _eventService.leaveEvent(payload['event_id']);
        break;
      case 'create_event':
        await _eventService.createEvent(
          title: payload['title'],
          description: payload['description'],
          latitude: payload['latitude'],
          longitude: payload['longitude'],
          address: payload['address'],
          startsAt: DateTime.parse(payload['starts_at']),
        );
        break;
    }
  }
}
```

```dart
      );
    }

    // 4. Supprimer les follows
    final follows = await databases.listDocuments(
      databaseId: 'fug_database',
      collectionId: 'followers',
      queries: [
        Query.or([
          Query.equal('follower_id', userId),
          Query.equal('followee_id', userId),
        ]),
      ],
    );

    for (final f in follows.documents) {
      await databases.deleteDocument(
        databaseId: 'fug_database',
        collectionId: 'followers',

      );
    }

    // 5. Supprimer les notifications
    final notifications = await databases.listDocuments(
      databaseId: 'fug_database',
      collectionId: 'notifications',
      queries: [Query.equal('user_id', userId)],
    );

    for (final n in notifications.documents) {
      await databases.deleteDocument(
        databaseId: 'fug_database',
        collectionId: 'notifications',
        documentId: n.$id,
      );
    }

    // 6. Anonymiser le profil utilisateur
```

### 7.4 Rate Limiting

Appwrite inclut un rate limiting integre, mais des limites custom peuvent etre ajoutees dans les Functions:

```dart
// Rate limiter simple avec Redis (si self-hosted avec Redis)
// Ou avec le cache Appwrite
class RateLimiter {
  final int maxRequests;
  final Duration window;
  final Map<String, List<DateTime>> _requests = {};

  RateLimiter({
    required this.maxRequests,
    required this.window,
  });

  bool isAllowed(String userId) {
    final now = DateTime.now();
    final userRequests = _requests[userId] ?? [];

    // Nettoyer les anciennes requetes
    userRequests.removeWhere(
      (time) => now.difference(time) > window,
    );

    if (userRequests.length >= maxRequests) {
      return false;
    }

    userRequests.add(now);
    _requests[userId] = userRequests;
    return true;
  }
}

// Utilisation dans une Function
final rateLimiter = RateLimiter(
  maxRequests: 10,
  window: Duration(minutes: 1),
);

if (!rateLimiter.isAllowed(userId)) {
  return context.res.json({
    'success': false,
    'message': 'Trop de requetes. Reessayez plus tard.'
  }, 429);
}
```
