## 1. Introduction

### 1.1 Objectif du document

Ce document d'analyse fonctionnelle decrit de maniere exhaustive l'ensemble des cas d'utilisation (use-cases) de l'application FUG. Il constitue la reference pour l'equipe de developpement et les parties prenantes concernant le comportement attendu du systeme.

### 1.2 Perimetre

Ce document couvre la version 1 (V1) de l'application FUG, un reseau social mobile permettant aux utilisateurs de trouver des compagnons de boisson via des evenements geolocalises appeles "FUG".

### 1.3 References

| Document | Description |
|:---------|:------------|
| 1. Document de vision.md | Vision du projet, exigences fonctionnelles et non fonctionnelles |

### 1.4 Conventions

- **UC-XX** : Identifiant unique d'un use-case
- **RB-UC-XX-Y** : Regle business associee au use-case XX
- **FA-UC-XX-Y** : Flux alternatif Y du use-case XX
- **FE-UC-XX-Y** : Flux d'exception Y du use-case XX

## 2. Glossaire

| Terme | Definition |
|:------|:-----------|
| **Visiteur** | Personne utilisant l'application sans etre authentifiee. Ne peut acceder qu'aux fonctionnalites publiques (inscription, authentification). |
| **Utilisateur** | Visiteur ayant cree un compte et s'etant authentifie. Accede a l'ensemble des fonctionnalites de l'application. |
| **Administrateur** | Utilisateur disposant de privileges eleves permettant de gerer le systeme (moderation, maintenance, configuration). |
| **Compte** | Ensemble des informations liees a un utilisateur, accessibles via ses identifiants (pseudo/email et mot de passe). |
| **FUG (ou Guinze, Murge)** | Evenement geolocalise initie par un utilisateur dans le but de partager un moment de convivialite autour d'une boisson. |
| **Preum's** | Utilisateur ayant initie (cree) une FUG. Il en est le responsable. |
| **Participant** | Utilisateur ayant rejoint une FUG creee par un autre utilisateur. |
| **Murgilarite** | Score de reputation d'un utilisateur, calcule selon son activite et sa participation aux FUG. Plus elle est elevee, plus l'utilisateur est considere comme un "parfait guinzeur". |
| **Follower (Abonne)** | Utilisateur s'etant abonne au flux d'activite d'un autre utilisateur. |
| **Following (Abonnement)** | Utilisateur dont on suit le flux d'activite. |
| **Rayon de reception** | Distance maximale autour de la position de l'utilisateur dans laquelle il recoit les notifications de nouvelles FUG. |

### UC-01 : S'inscrire

#### Definition

| Element | Description |
|--------:|:------------|
| **ID** | UC-01 |
| **Nom** | S'inscrire |
| **But** | Permettre a un visiteur de creer un compte sur l'application FUG |
| **Acteur principal** | Visiteur |
| **Acteurs secondaires** | Services de reseaux sociaux, Serveur mail |
| **Declencheur** | Le visiteur souhaite acceder aux fonctionnalites de l'application |
| **Preconditions** | - Le visiteur n'est pas authentifie<br>- Le visiteur n'a pas deja de compte avec le meme email/pseudo |
| **Postconditions (succes)** | - Un compte utilisateur est cree dans le systeme<br>- Un email de confirmation est envoye<br>- L'utilisateur peut s'authentifier |
| **Postconditions (echec)** | - Aucun compte n'est cree<br>- Le visiteur est informe de la raison de l'echec |

#### Flux principal

| Etape | Acteur | Action | Systeme |
|:-----:|:-------|:-------|:--------|
| 1 | Visiteur | Lance l'application et selectionne "Creer un compte" | |
| 2 | | | Affiche le formulaire d'inscription avec les champs : pseudo, email, mot de passe, confirmation mot de passe, date de naissance |
| 3 | Visiteur | Remplit les champs du formulaire et accepte les CGU | |
| 4 | | | Valide les donnees saisies (format, unicite) |
| 5 | | | Cree le compte utilisateur avec le statut "En attente de confirmation" |
| 6 | | | Envoie un email de confirmation contenant un lien d'activation |
| 7 | | | Affiche un message de succes : "Un email de confirmation vous a ete envoye" |
| 8 | Visiteur | Ouvre l'email et clique sur le lien d'activation | |
| 9 | | | Active le compte (statut "Actif") |
| 10 | | | Redirige vers l'ecran d'authentification avec message de succes |

#### Flux alternatifs

**FA-UC-01-1 : Inscription via reseau social**

| Etape | Acteur | Action | Systeme |
|:-----:|:-------|:-------|:--------|
| 1a | Visiteur | Selectionne "S'inscrire avec Facebook/Google/Twitter" | |
| 2a | | | Redirige vers la page d'autorisation du reseau social |
| 3a | Visiteur | Autorise l'application a acceder a ses informations | |
| 4a | | | Recupere les informations du profil (nom, email, photo) |
| 5a | | | Affiche un formulaire pre-rempli avec demande de pseudo et date de naissance |
| 6a | Visiteur | Complete les informations manquantes et valide | |
| 7a | | | Cree le compte avec statut "Actif" (email deja verifie par le reseau social) |
| 8a | | | Authentifie automatiquement l'utilisateur et redirige vers l'ecran principal |

#### Flux d'exception

**FE-UC-01-1 : Email deja utilise**

| Etape | Systeme |
|:-----:|:--------|
| 4a | Detecte que l'email existe deja en base |
| 4b | Affiche le message d'erreur : "Cette adresse email est deja associee a un compte" |
| 4c | Propose le lien "Mot de passe oublie ?" |

**FE-UC-01-2 : Pseudo deja utilise**

| Etape | Systeme |
|:-----:|:--------|
| 4a | Detecte que le pseudo existe deja en base |
| 4b | Affiche le message d'erreur : "Ce pseudo est deja pris" |
| 4c | Suggere des pseudos alternatifs disponibles |

**FE-UC-01-3 : Age insuffisant**

| Etape | Systeme |
|:-----:|:--------|
| 4a | Calcule l'age a partir de la date de naissance |
| 4b | Detecte que l'utilisateur n'a pas l'age legal |
| 4c | Affiche le message : "Vous devez avoir l'age legal de consommation d'alcool dans votre pays pour utiliser FUG" |
| 4d | Bloque l'inscription |

**FE-UC-01-4 : Lien de confirmation expire**

| Etape | Systeme |
|:-----:|:--------|
| 9a | Detecte que le lien a expire (delai > 24h) |
| 9b | Affiche le message : "Ce lien a expire" |
| 9c | Propose de renvoyer un nouveau lien de confirmation |

**FE-UC-01-5 : Erreur de connexion au reseau social**

| Etape | Systeme |
|:-----:|:--------|
| 4a | Echec de la connexion au service tiers |
| 4b | Affiche le message : "Impossible de se connecter a [Reseau social]. Veuillez reessayer." |
| 4c | Retourne au formulaire d'inscription |

#### Regles business

| ID | Regle |
|:---|:------|
| RB-UC-01-1 | Le pseudo doit contenir entre 3 et 20 caracteres alphanumeriques (lettres, chiffres, underscore) |
| RB-UC-01-2 | L'email doit etre au format valide et unique dans le systeme |
| RB-UC-01-3 | Le mot de passe doit contenir au minimum 8 caracteres, dont 1 majuscule, 1 minuscule et 1 chiffre |
| RB-UC-01-4 | L'utilisateur doit avoir l'age legal de consommation d'alcool de son pays (18 ans minimum par defaut) |
| RB-UC-01-5 | Le lien de confirmation est valide pendant 24 heures |
| RB-UC-01-6 | Les CGU doivent etre acceptees pour finaliser l'inscription |
| RB-UC-01-7 | Un compte reseau social ne peut etre lie qu'a un seul compte FUG |

| Element | Description |

| 4 | Visiteur | Appuie sur "Se connecter" | |
| 5 | | | Verifie les identifiants dans la base de donnees |
| 6 | | | Verifie que le compte est actif |
| 7 | | | Cree une session utilisateur et genere un token d'authentification |
| 8 | | | Met a jour la date de derniere connexion |

**FE-UC-02-1 : Identifiants incorrects**

**FE-UC-02-3 : Compte non active**

| Etape | Systeme |

| 6b | Affiche "Votre compte n'est pas encore active. Verifiez vos emails." |
| 6c | Propose de renvoyer l'email de confirmation |

**FE-UC-02-4 : Compte desactive**

| Etape | Systeme |
|:-----:|:--------|
| 6a | Detecte que le compte a le statut "Desactive" |
| 6b | Affiche "Votre compte a ete desactive. Contactez le support." |

**FE-UC-02-5 : Compte reseau social non lie**

| Etape | Systeme |
|:-----:|:--------|
| 6a | Aucun compte FUG n'est associe a ce compte reseau social |

**FE-UC-02-6 : Lien de reinitialisation expire**

| Etape | Systeme |
|:-----:|:--------|

#### Regles business

| ID | Regle |
|:---|:------|
| RB-UC-02-1 | L'identifiant peut etre le pseudo OU l'adresse email |
| RB-UC-02-2 | Apres 5 tentatives echouees consecutives, le compte est bloque pendant 15 minutes |
| RB-UC-02-3 | Le token d'authentification standard expire apres 24 heures d'inactivite |
| RB-UC-02-4 | Le token "Rester connecte" expire apres 30 jours |
| RB-UC-02-5 | Le lien de reinitialisation de mot de passe est valide pendant 1 heure |
| RB-UC-02-6 | La reinitialisation du mot de passe invalide toutes les sessions actives |

## 7. Annexes

### 7.1 Regles de calcul de la murgilarite

| Action | Points |
|:-------|:------:|
| Creer une FUG | +10 |
| Rejoindre une FUG | +5 |
| Recevoir un participant sur sa FUG | +2 |
| Avoir un nouveau follower | +1 |
| FUG terminee avec 5+ participants | +5 (bonus Preum's) |
| Premiere FUG de la semaine | +3 (bonus hebdo) |

### 7.2 Etats d'une FUG

```
[Planifiee] ---(heure atteinte)---> [Active] ---(24h sans activite OU terminee par Preum's)---> [Terminee]
                                       |
                                       +---(suppression admin)---> [Supprimee]
```

### 7.3 Etats d'un compte utilisateur

```
[En attente de confirmation] ---(clic lien)---> [Actif] ---(desactivation volontaire)---> [Desactive]
                                                   |
                                                   +---(suspension admin)---> [Suspendu]
                                                   |
                                                   +---(bannissement admin)---> [Banni]
```

### 7.4 Glossaire des messages d'erreur

| Code | Message | Contexte |
|:-----|:--------|:---------|
| ERR-AUTH-001 | "Identifiant ou mot de passe incorrect" | Authentification echouee |
| ERR-AUTH-002 | "Compte temporairement bloque" | Trop de tentatives |
| ERR-AUTH-003 | "Compte non active" | Email non confirme |
| ERR-REG-001 | "Cette adresse email est deja utilisee" | Email duplique |
| ERR-REG-002 | "Ce pseudo est deja pris" | Pseudo duplique |
| ERR-REG-003 | "Age minimum requis non atteint" | Verification age |
| ERR-FUG-001 | "Limite de FUG actives atteinte" | Max 3 FUG |
| ERR-FUG-002 | "Cette FUG est terminee" | FUG plus active |
| ERR-GEN-001 | "Geolocalisation requise" | GPS desactive |
